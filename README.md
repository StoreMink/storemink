# StoreMink

Multi-tenant commerce platform: storefronts, the merchant dashboard, POS and
Mink AI. Next.js 16 on Google Cloud: Cloud Run, Cloud SQL for PostgreSQL
(Drizzle), Cloud Storage, Identity Platform, Cloud Build and Cloud Scheduler.

- Read first: `CODEBASE.md` (the codebase map) and `AGENTS.md` (working rules).
- Run locally: `npm run dev`, then open http://localhost:3000. Local database:
  `docs/local-dev-performance.md`.
- Deploys and environments: `docs/gcp-ci-cd.md`. Scheduled jobs:
  `docs/cron-jobs.md`. Database migrations: `docs/migrations.md`.
